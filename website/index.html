02多网盘冗余

不把笔记，押在一家网盘上

同一份笔记，同时存到你自己的多个网盘和仓库。任何一家关停、涨价、出故障，你的数据都安然无恙。

  • WebDAV、S3、Git 同时配置，一份内容多处副本，这才叫冗余
  • 不锁定任何厂商，坚果云、NAS、Nextcloud、OSS、MinIO 都支持
  • 断点续传、限流退避、弱网熔断，大文件、差网络也能同步完
  • 删除安全闸、冲突双版本，误删和多端编辑都不丢一个字
  • 同步走你自己的网盘，官方不经手、不中转，零订阅费

隐私承诺

你的笔记，只属于你

我们相信，笔记软件最大的责任是「不越界」。云舟从架构层面，把这四件事写进了产品的地基。

数据是本地文件

所有笔记以纯 Markdown 存放在你自己的硬盘，不进官方服务器、不依赖云端账号，断网也能完整使用。

AI 用你自己的资源

可自带云端 API Key，或下载本地模型离线推理；官方不经手、不收集你的笔记内容，Key 只保存在本机。

AI 不静默写库

每一条改动都遵循「提议 → 审批」，由你确认后才执行；操作全程留痕、可撤销，AI 没有擅自修改的权限。

开放格式，随时迁移

坚持开放数据格式，不做私有锁。任何时候你都能完整导出、用别的编辑器打开，离开云舟没有任何代价。

同步与备份发生在你自己配置的网盘（WebDAV / S3 / Git），云舟官方不中转、不留存你的文件内容。
