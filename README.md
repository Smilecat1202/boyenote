纯 Markdown、本地优先，多网盘冗余同步、不丢东西；AI 助手「小叶」帮你整理标签、摘要与分类，但**所有改动都经你确认——它永远不替你乱动**。

不做锁在云端的黑盒，也不做需要反复折腾的极客玩具。拨叶在「好用」和「自主」之间，把两头都占住。

## ✨ 核心特性

### 01 · 好用的本地笔记
- **所见即所得编辑器**：基于 CodeMirror，字节级保真，不擅自改动你的文字。
- **多种视图组织知识**：文件夹、速记、标签、回顾、知识图谱随心切换。
- **关键词 + 语义混合检索**：毫秒级定位，本地向量补充召回，PDF 正文也搜得到。
- **拍照取字 / 图片理解**：拍纸质文档、白板自动提取文字，还能就图片提问、让 AI 配文。
- **录音转写**：离线语音模型按需下载，录音转文字后自动校正，中英文混读也能处理。
- **附件与素材**：附件规范化、图片 / PDF 预览，素材和文字放在一起。
- **离线可用**：本地运行，飞机上、断网时照样写。

### 02 · 多网盘冗余
- **WebDAV、S3、Git 同时配置**，一份内容多处副本，这才叫冗余。
- **不锁定任何厂商**：坚果云、InfiniCloud、NAS、Nextcloud、OSS、MinIO、GitHub / Gitee 都支持。
- **断点续传、限流退避、弱网熔断**，大文件、差网络也能同步完。
- **删除安全闸、冲突双版本**，误删和多端编辑都不丢一个字。
- 同步走**你自己的网盘**，官方不经手、不中转，零订阅费。

### 03 · AI 助手「小叶」
- **智能标题、标签、摘要、分类**，划词即可处理，记录完自动归位。
- **对话问答、就这篇 / 这张图提问**，回答可追溯，不做无凭无据的结论。
- **所有改动都经你确认**：AI 提议、你审批，从不静默写库。
- **自带云端 Key 或本地模型**，内容不外传，费用你自己定。
- 拍照取字、录音转写后的**自动校正**，让记录更干净。

## 🔒 隐私承诺

- **数据是本地文件**：所有笔记以纯 Markdown 存在你自己的设备，不进官方服务器、不依赖云端账号。
- **AI 用你自己的资源**：可自带云端 API Key，或用本地模型离线推理；官方不收集你的笔记内容，Key 只保存在本机安全存储。
- **AI 不静默写库**：每条改动都遵循「提议 → 确认」，由你同意后才执行，全程可留痕、可撤销。
- **开放格式，随时迁移**：坚持开放数据格式、不做私有锁定，任何时候都能完整导出，用别的编辑器打开。
