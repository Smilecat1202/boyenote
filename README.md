纯 Markdown、本地优先，多网盘冗余同步、不丢东西；AI 帮你整理标签、摘要与分类，但**所有改动都经你审批——它永远不替你乱动**。

不做锁在云端的黑盒，也不做需要反复折腾的极客玩具。云舟在「好用」和「自主」之间，把两头都占住。

## ✨ 核心特性

### 01 · 好用的本地笔记软件
- **所见即所得编辑器**：基于 CodeMirror 6，字节级保真，不擅自改动你的文字。
- **多种视图组织知识**：看板、日记、回顾、标签、模板、知识图谱随心切换。
- **关键词 + 语义混合检索**：⌘K 毫秒级定位，本地向量补充召回，PDF 正文也搜得到。
- **附件与素材**：附件规范化、图片 / PDF 预览，素材和文字放在一起。
- **离线可用**：本地运行，飞机上、断网时照样写。

### 02 · 多网盘冗余
- **WebDAV、S3、Git 同时配置**，一份内容多处副本，这才叫冗余。
- **不锁定任何厂商**：坚果云、NAS、Nextcloud、OSS、MinIO、GitHub / Gitee 都支持。
- **断点续传、限流退避、弱网熔断**，大文件、差网络也能同步完。
- **删除安全闸、冲突双版本**，误删和多端编辑都不丢一个字。
- 同步走**你自己的网盘**，官方不经手、不中转，零订阅费。

### 03 · AI 功能
- **智能标题、标签、摘要、分类**，划词即可处理，记录完自动归位。
- **对话问答、联网检索附来源**，结论可追溯，不做无凭无据的回答。
- **AI 审批中心**：覆盖 16 类巡检，提议 → 你审批，从不静默写库。
- **自带云端 Key 或本地模型**，内容不外传，费用你自己定。
- 未来 Pro：闲时夜班、周 / 月复盘、知识园艺，让 AI 主动干活。

## 🔒 隐私承诺

- **数据是本地文件**：所有笔记以纯 Markdown 存在你自己的硬盘，不进官方服务器、不依赖云端账号。
- **AI 用你自己的资源**：可自带云端 API Key，或用本地模型离线推理；官方不收集你的笔记内容，Key 只保存在本机。
- **AI 不静默写库**：每条改动都遵循「提议 → 审批」，由你确认后才执行，全程可留痕、可撤销。
- **开放格式，随时迁移**：坚持开放数据格式、不做私有锁定，任何时候都能完整导出，用别的编辑器打开。
