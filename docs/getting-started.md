# 快速开始

几分钟把拨叶用起来。

## 1. 下载安装

- **Android**：下载 `.apk` 后安装（需允许「安装未知来源应用」），要求 Android 8 及以上。
- **macOS**：从官网下载 `.dmg`，打开后将「拨叶」拖入「应用程序」，支持 Apple Silicon 与 Intel。
  - 首次打开若提示「无法验证开发者」，请到「系统设置 → 隐私与安全性」点击「仍要打开」。

## 2. 选择笔记库

首次启动时选择一个本地文件夹作为「笔记库」。库里的每一篇笔记都是普通的 `.md` 文件，你可以随时用其他编辑器打开，也可以随时更换或新建库。

## 3. 写第一篇笔记

- 编辑器所见即所得，直接输入即可；想查看 Markdown 源码也可切换。
- 拨叶坚持**字节级保真**：它不会在你不知情时改动文件内容、不自动注入多余信息。
- 底部可在速记、文档、回顾、我的之间切换，速记里可快速记录文字、拍照、录音。

## 4. 下载离线语音模型（按需）

录音转文字使用本地语音模型，安装包不内置模型。首次使用录音时，应用会提示你下载：

- 模型约 230MB，仅在本地用于录音转文字，不涉及上传。
- 下载支持断点续传、多源切换，国内访问也有稳定兜底。
- 你可以稍后在「我的 → 语音转写模型」中查看就绪状态、补下载或删除模型。

## 5. 配置多网盘同步（可选）

在「我的 → 网盘同步」中添加一个或多个目标，建议至少配两个，形成冗余：

- **WebDAV**：坚果云、InfiniCloud、群晖 / 威联通 NAS、Nextcloud 等。以坚果云为例，在「账户信息 → 安全选项 → 第三方应用管理」生成应用密码，连同服务器地址、账号填入即可。
- **S3 兼容**：阿里云 OSS、腾讯云 COS、MinIO 等，填入 Endpoint、Region、Bucket、AccessKey / Secret。
- **Git**：可指向 GitHub / Gitee 仓库。

配置后，同一份内容会同步到多个目标。弱网下支持断点续传与限流退避；多端冲突会保留双版本，不丢内容。

## 6. 配置 AI 助手（可选）

在「我的 → AI 助手」中配置云端模型：

- 选择服务商，填入你自己的 API Key（费用由你与服务商结算，Key 只保存在本机安全存储）。
- 点击「测试连接并选择模型」，从返回的模型列表中点选一个，再点「保存」。
- 未配置时，拍照取字、录音转写的**离线能力**照常可用；AI 校正、对话、图片理解等需要云端模型的能力暂不可用。

## 常用操作

- 全局搜索：在「文档」页顶部搜索框输入关键词。
- 其余操作以应用内实际标注为准。
