# 快速开始

几分钟把云舟用起来。

## 1. 下载安装

- **macOS**：从 [Releases](https://github.com/Smilecat1202/cloudnote/releases) 下载 `.dmg`，打开后将「云舟笔记」拖入「应用程序」。支持 Apple Silicon 与 Intel。
  - 首次打开若提示「无法验证开发者」，请到「系统设置 → 隐私与安全性」点击「仍要打开」。
- **Android**：下载 `.apk` 后安装（需允许「安装未知来源应用」），要求 Android 8 及以上。

## 2. 选择笔记库

首次启动时选择一个本地文件夹作为「笔记库（Vault）」。库里的每一篇笔记都是普通的 `.md` 文件，你可以随时用其他编辑器打开，也可以随时更换或新建库。

## 3. 写第一篇笔记

- 编辑器所见即所得，直接输入即可；想查看 Markdown 源码也可切换。
- 云舟坚持**字节级保真**：它不会在你不知情时改动文件内容、不自动注入 frontmatter。
- 左侧可切换看板、日记、回顾、标签、模板、知识图谱等视图。

## 4. 配置多网盘冗余（可选）

在「设置 → 同步」中添加一个或多个目标，建议至少配两个，形成冗余：

- **WebDAV**：坚果云、群晖 / 威联通 NAS、Nextcloud 等。以坚果云为例，在坚果云「账户信息 → 安全选项 → 第三方应用管理」生成应用密码，填入服务器地址、账号与该应用密码即可。
- **S3 兼容**：阿里云 OSS、腾讯云 COS、MinIO 等，填入 Endpoint、Region、Bucket、AccessKey / Secret。
- **Git**：可指向 GitHub / Gitee 仓库。

配置后，同一份内容会同时同步到多个目标。弱网下支持断点续传与限流退避；删除操作有安全闸，多端冲突会保留双版本，不丢内容。

## 5. 配置 AI（可选）

在「设置 → AI」中二选一或都配：

- **云端模型**：填入你自己的 API Key（费用由你与服务商结算，Key 只保存在本机）。
- **本地模型**：下载如 Qwen 等本地小模型，完全离线推理，笔记内容不出本机。

## 6. AI 审批中心

AI 巡检会把发现的问题（重复、空文件、命名、失效链接等 16 类）汇总到「审批中心」，逐条列出建议改动。你确认后它才执行，操作可撤销、可审计——AI 不会静默写库。

## 常用操作

- 全局搜索 / 命令面板：`⌘K`（macOS）/ `Ctrl+K`（Windows）。
- 其余快捷键以应用内菜单实际标注为准。
