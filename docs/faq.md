# 常见问题

### 云舟笔记是免费的吗？

编辑器、本地视图、多网盘同步、基础 AI、混合检索等核心功能永久免费。上线后会推出可选的 CloudNote Pro，把「会主动干活的 AI」（闲时夜班、复盘、知识园艺等）作为增量能力，基础功能不会因此缩水。

### 我的数据安全吗？会不会被锁定？

数据就是你硬盘里的纯 Markdown 文件，不进官方服务器、不依赖账号，任何编辑器都能打开。坚持开放数据格式，可随时完整导出和迁移，离开云舟没有任何代价。

### 必须联网或注册账号吗？

都不需要。应用本地运行、离线可用，也没有账号系统。同步只在你配置好自己的网盘后发生；AI 可使用本地模型离线推理，或用你自己的云端 Key。

### AI 会不会擅自修改我的笔记？

不会。AI 整理中心遵循「巡检 → 提议 → 人工审批」，每条改动都列给你看、由你确认后才执行，操作可撤销、可审计，AI 没有静默写库的权限。

### 它和 Obsidian、思源、Notion 有什么区别？

- 相比 Notion：云舟本地优先、离线可用、数据不被云端锁定。
- 相比 Obsidian：云舟 AI 原生、开箱即用，不用依赖大量插件拼装。
- 相比思源：云舟采用 Tauri 架构、安装包小、界面更轻，并内置 AI 审批与多网盘冗余。

### 支持哪些平台？

首发支持 macOS 与 Android，Windows 于 11 月中跟进，iOS、Linux 后续推出。

### 支持哪些同步方式？

支持 WebDAV（坚果云 / NAS / Nextcloud）、S3 兼容（OSS / COS / MinIO）与 Git，可同时配置、冗余备份。同步走你自己的网盘，官方不经手内容。

### 配置 WebDAV / S3 需要付费给云舟吗？

不需要。同步使用的是你自己的网盘账号，云舟不收取任何同步费用，也不中转你的数据。
