# 常见问题

### 拨叶是免费的吗？

编辑器、本地视图、多网盘同步、拍照取字、录音转写、混合检索等核心功能永久免费。后续可能推出可选的增值能力，基础功能不会因此缩水。

### 我的数据安全吗？会不会被锁定？

数据就是你设备里的纯 Markdown 文件，不进官方服务器、不依赖账号，任何编辑器都能打开。坚持开放数据格式，可随时完整导出和迁移，离开拨叶没有任何代价。

### 必须联网或注册账号吗？

都不需要。应用本地运行、离线可用，也没有账号系统。同步只在你配置好自己的网盘后发生；录音转写、拍照取字使用本地模型，可离线完成。

### 录音转写要联网吗？

转写本身在本地完成，不需要联网。语音模型按需下载（约 230MB，仅一次），之后离线即可转写。若开启了「AI 校正」，校正这一步会调用你配置的云端模型，需要联网；未配置时仅给出离线转写原文。

### AI 会不会擅自修改我的笔记？

不会。AI 的每条改动都列给你看、由你确认后才执行，操作可撤销、可追溯，AI 没有静默写库的权限。

### 配置网盘 / AI 需要付费给拨叶吗？

不需要。同步使用的是你自己的网盘账号，AI 用的是你自己的 API Key，拨叶不收取任何费用，也不中转你的数据。

### 它和 Obsidian、思源、Notion 有什么区别？

- 相比 Notion：拨叶本地优先、离线可用、数据不被云端锁定。
- 相比 Obsidian：拨叶 AI 原生、开箱即用，不用依赖大量插件拼装。
- 相比思源：拨叶采用 Tauri 架构、安装包小、界面更轻，并内置 AI 助手与多网盘冗余。

### 支持哪些平台？

目前支持 Android（内测）与 macOS（内测），Windows 正在开发中，iOS、Linux 已规划。

### 支持哪些同步方式？

支持 WebDAV（坚果云 / InfiniCloud / NAS / Nextcloud）、S3 兼容（OSS / COS / MinIO）与 Git，可同时配置、冗余备份。同步走你自己的网盘，官方不经手内容。
